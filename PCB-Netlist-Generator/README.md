# Netlist Generator

Welcome to the **Netlist Generator**! This project converts circuit schematic images into structured **netlists**, enabling automated circuit analysis, simulation, and verification. It uses YOLOv8 for component detection and pin localization, alongside text removal and image preprocessing techniques.

---

## Folder Structure

| Folder | Description |
|--------|-------------|
| **Current trained model/** | Contains the most recent trained YOLOv8 pose model (`train*/weights/last.pt`). |
| **Model training/** | Scripts and tools for training and converting CVAT annotations to COCO format. |
| **Program test/** | All testing and visualization scripts, including GUI tools and pin detection. |
| **Final/** | All final scripts that can be used to run the programs. Navigate to this folder for final codes.
| **Results/** | All results obtained till date.

## How to Train Your Own Model

To fine-tune YOLO for your own circuit datasets, follow the steps below.

### Step 1: Annotate Images with CVAT

- Use the CVAT tool to label circuit components and pin keypoints.
- Export your annotations in **CVAT Keypoints format**.

---

#### How Text Removal Works (`text_remove.py`)

This script uses the Google Cloud Vision API to detect printed text (especially light grey labels) in circuit schematics, then removes it either by inpainting or by filling with white.

---

#### Key Configuration Parameters

```python
symbol_expand  = 1       # Expand OCR bounding boxes by 1 pixel
sat_thresh     = 30      # Max saturation to consider as grey
val_thresh     = 150     # Min brightness to consider as grey
FULL_SCALE     = 4.0     # Zoom factor for tiny text detection
inpaint_method = 'white' # Options: 'white', 'telea', or 'ns'
```

These thresholds help filter out light-colored text while preserving circuit lines and component edges.

#### Native OCR and Masking
The function below performs OCR on the image and masks detected grey text regions:
```python
def ocr_grey_mask(img):
    H, W = img.shape[:2]
    mask = np.zeros((H, W), dtype=np.uint8)

    # Encode the image and send to Vision API
    _, enc = cv2.imencode('.png', img)
    gv = vision.Image(content=enc.tobytes())
    ann = vision_client.document_text_detection(image=gv).full_text_annotation

    for page in ann.pages:
        for block in page.blocks:
            for para in block.paragraphs:
                for word in para.words:
                    for sym in word.symbols:
                        xs = [v.x for v in sym.bounding_box.vertices]
                        ys = [v.y for v in sym.bounding_box.vertices]
                        x1 = max(0, min(xs) - symbol_expand)
                        y1 = max(0, min(ys) - symbol_expand)
                        x2 = min(W, max(xs) + symbol_expand)
                        y2 = min(H, max(ys) + symbol_expand)
                        roi = img[y1:y2, x1:x2]
                        if roi.size == 0:
                            continue
                        hsv = cv2.cvtColor(roi, cv2.COLOR_BGR2HSV)
                        grey = (hsv[:, :, 1] < sat_thresh) & (hsv[:, :, 2] > val_thresh)
                        mask[y1:y2, x1:x2][grey] = 255

    return mask
```
#### High-Resolution Pass for Tiny Text
Some labels are very small, so the image is also zoomed in and reprocessed:

```python 
def ocr_grey_mask_zoom(img):
    H, W = img.shape[:2]
    hi, hj = int(W * FULL_SCALE), int(H * FULL_SCALE)
    img_hi = cv2.resize(img, (hi, hj), interpolation=cv2.INTER_CUBIC)

    _, enc = cv2.imencode('.png', img_hi)
    gv = vision.Image(content=enc.tobytes())
    ann = vision_client.document_text_detection(image=gv).full_text_annotation

    mask_hi = np.zeros((hj, hi), dtype=np.uint8)

    for page in ann.pages:
        for block in page.blocks:
            for para in block.paragraphs:
                for word in para.words:
                    for sym in word.symbols:
                        xs = [v.x for v in sym.bounding_box.vertices]
                        ys = [v.y for v in sym.bounding_box.vertices]
                        x1 = max(0, min(xs) - symbol_expand)
                        y1 = max(0, min(ys) - symbol_expand)
                        x2 = min(hi, max(xs) + symbol_expand)
                        y2 = min(hj, max(ys) + symbol_expand)
                        roi_hi = img_hi[y1:y2, x1:x2]
                        if roi_hi.size == 0:
                            continue
                        hsv = cv2.cvtColor(roi_hi, cv2.COLOR_BGR2HSV)
                        grey = (hsv[:, :, 1] < sat_thresh) & (hsv[:, :, 2] > val_thresh)
                        mask_hi[y1:y2, x1:x2][grey] = 255

    mask = cv2.resize(mask_hi, (W, H), interpolation=cv2.INTER_NEAREST)
    return mask
```
#### Final Text Removal
Once the masks are built, the text can be removed either by filling or inpainting.

Option 1: Fill with white
```python
out = img.copy()
out[mask == 255] = (255, 255, 255)
```
Option 2:Inpaint using OpenCV
```python
flag = cv2.INPAINT_TELEA if inpaint_method == 'telea' else cv2.INPAINT_NS
out = cv2.inpaint(img, mask, inpaintRadius=3, flags=flag)
```

### Step 5: Detect Pin Positions with Edge Scanning

After removing text, run the edge detection script to find pin positions for each detected component:

```bash
py .\edge_detection.py
```

This script performs the following steps:

*   Loads the trained YOLO model and runs inference on the text-removed images
    
*   Applies adaptive thresholding to isolate high-contrast features
    
*   Scans the top, bottom, left, and right edges of each bounding box
    
*   Identifies pin coordinates based on white pixel clusters near the edges
    
*   Saves output images with green dots indicating pin locations
    

Output location:Model test/Model test results/

#### How Pin Detection Works (`edge_detection.py`)

This script uses YOLOv8 to detect circuit components, then refines each detected bounding box using contour analysis and identifies pin positions by scanning the edges of the component.

---

#### Bounding Box Refinement

The function below refines YOLO-detected bounding boxes based on color contrast:

```python
def refine_bbox_by_contour(image, bbox, expand_pixels=0):
    ...
    lower_dark = np.array([0, 0, 0])
    upper_dark = np.array([180, 255, 50])
    mask = cv2.inRange(hsv, lower_dark, upper_dark)
    ...
    contours, _ = cv2.findContours(mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
    ...
    refined_bbox = (x_min + x, y_min + y, x_min + x + w, y_min + y + h)
    return refined_bbox
```
What it does:

* Converts the region to HSV color space.

* Filters out light areas and isolates dark outlines typical of component borders.

* Finds the largest contour and returns a tighter, more accurate bounding box.

Key parameters:

* bbox: Bounding box from YOLO detection.

* expand_pixels: Additional padding (default is 0 since we want precision).

#### Pin Detection Logic
This function finds pin locations along the edges of the bounding box:

```python
def detect_pins(image, bbox, expand_pixels=5):
    ...
    gray = cv2.cvtColor(component, cv2.COLOR_BGR2GRAY)
    binary = cv2.adaptiveThreshold(gray, 255,
                                   cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
                                   cv2.THRESH_BINARY_INV, 11, 2)
    ...
    for x in range(binary.shape[1]):
        for y in range(3):  # Top edge
            if binary[y, x] == 255:
                top_pins.append((x_min + x, y_min + y))
                break
```
#### What it does:

* Applies adaptive thresholding to highlight small bright details (pins).

* Scans the top, bottom, left, and right 3-pixel borders.

* Appends pin coordinates where white blobs are found.

#### Key parameters:

* expand_pixels=5: Expands the bounding box to ensure no edge pin is missed.

* Returns four lists: top_pins, bottom_pins, left_pins, and right_pins.
